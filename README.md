# 📚 S01 - Paradigmas da Programação

##  Propósito do Repositório

Este repositório tem como objetivo hospedar e centralizar os códigos, exercícios práticos e trabalhos desenvolvidos durante a disciplina de **Paradigmas da Programação (S01)**. 

Ele atua como um portfólio de soluções computacionais construídas sob diferentes abordagens arquiteturais (Imperativa, Orientada a Objetos, Funcional e Lógica). A proposta aqui é armazenar a aplicação prática de cada paradigma na resolução dos problemas específicos que foram propostos ao longo do período acadêmico.
